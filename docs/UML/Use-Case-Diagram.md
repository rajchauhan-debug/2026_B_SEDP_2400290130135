# CampusCareer – Use Case Diagram

## Actors

### Student
The Student uses CampusCareer to register, log in, manage profile, view placement and internship opportunities, apply for opportunities, and track application status.

### Admin
The Admin manages placement and internship opportunities and student applications.

## Student Use Cases

- Register
- Login
- Manage Profile
- View Opportunities
- Apply for Opportunity
- Track Application Status

## Admin Use Cases

- Login
- Add Opportunity
- Delete Opportunity
- View Applications
- Update Application Status
