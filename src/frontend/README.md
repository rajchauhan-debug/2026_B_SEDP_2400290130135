# CampusCareer Frontend Prototype

A responsive, browser-only frontend prototype for the CampusCareer Student Placement & Internship Management System.

## Files
- `index.html` — page structure and sections
- `style.css` — responsive styling
- `app.js` — demo interactions and local browser storage

## Run it
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Try the sidebar pages, opportunity search/filter, save button, Quick apply, application tracker, and profile form.

## Important scope note
This is a frontend prototype. Opportunities are sample data, applications are demo records, and profile/application state is stored in this browser's `localStorage`. There is no real authentication, backend API, or MongoDB connection yet. Do not use real passwords or sensitive information.
