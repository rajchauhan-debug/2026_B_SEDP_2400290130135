# CampusCareer

## Student Placement & Internship Management System

CampusCareer is a simple web-based system designed to help students
view placement and internship opportunities, apply for them, and
track their application status.

- Express.js
- MongoDB
- Git
- GitHub
- VS Code
- Postman

## Main Features

### Student

- Register and Login
- Manage Profile
- View Jobs and Internships
- Apply for Opportunities
- Check Application Status

### Admin

- Login
- Add Job or Internship
- Delete Job or Internship
- View Student Applications
